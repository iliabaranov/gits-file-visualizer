A live GNOME desktop wallpaper that renders your filesystem as the glowing
security-system tower from *Ghost in the Shell 2: Innocence*. Directories are
bands of rings, files are arc segments; reads flash, writes turn crimson, new
files grow and deleted files fall apart. Callouts name the files being touched.

## Highlights

- **Wallpaper on every monitor** through a GNOME Shell extension, including the
  overview and workspace switching; covered monitors pause.
- **GNOME 42-44 and 45-46**, Wayland and X11. The GNOME 45+ extension was
  developed and tested on GNOME 46 (Ubuntu 24.04), live on X11 and in a nested
  Wayland shell.
- **Screensaver** (GNOME 45+): after a configurable idle time the tower takes
  over every screen until you touch the machine or GNOME blanks the display.
- **Live lock screen** (opt-in, `[lock_screen] live = true`): the tower runs
  behind the clock and password prompt, on black, with file names hidden. On
  GNOME 45+ the display stays lit until the blank time instead of blanking the
  moment you lock.
- **Power aware**: integrated or discrete GPU, frame-rate caps on battery,
  `pause_on_battery`, and pausing while the displays are off.
- **Sharp on integrated GPUs** with `integrated_native_window`; measured GPU
  cost per frame rate is in the README.
- **Privacy options**: hide or obfuscate file names, including while a screen
  share is running.
- A collector service watches your home folder (names, sizes and times, never
  contents; no network) and streams changes to the renderer.
- `gits-restart` for a clean restart of the wallpaper.

## Install

Prebuilt bundle (x86_64 Linux, glibc 2.35+, Ubuntu 22.04 or newer; no Rust
needed):

```sh
tar xzf gits-file-visualizer-linux-x86_64.tar.gz && gits-file-visualizer/install.sh
```

Verify the download with the `.sha256` file; it also has a GitHub build
attestation (`gh attestation verify <file> --repo iliabaranov/gits-file-visualizer`).
On X11, restart the shell once (Alt+F2, `r`) after installing; on Wayland, log
out and in. Or build from source: see the README.

## Known limitations

- The screensaver and the lit lock screen are GNOME 45+ only.
- The GNOME 42-44 extension was last tested before the 0.1 changes to the lock
  screen code; the GNOME 47+ shells are untested.
- Only 32,768 directories are watched live by default (the inotify limit);
  others are checked by a periodic crawl. See "Watch limit" in the README.
- On battery, laptops that suspend on idle will suspend before a long
  screensaver ends.
