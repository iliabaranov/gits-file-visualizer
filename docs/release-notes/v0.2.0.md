A disk usage chart joins the system readout, and the live lock screen now
shows everything: the tower's callouts, the readout and the chart, with names
anonymized.

## New

- **Disk usage chart**, above the system readout in the lower right. An inner
  gauge shows how full the disk is (bright gold: your home folder, dim gold:
  everything else that is used, grey: free; crimson above 90% full). Up to three
  rings show which folders in your home folder use the space, the five largest
  labelled with their size. The home folder is measured like `du -x`, so caches
  and build folders count (the tower leaves those out): on a background thread
  at idle CPU and I/O priority, every 30 minutes, only while the readout is on
  screen, and cached in `~/.cache/gits-file-visualizer` so restarts do not
  re-measure.
- **Scanning animation**: while the disk is re-measured, a slow gold sweep goes
  round the previous result and SCANNING shows beside the title.
- **`gits-restart` re-measures the disk** as well (the dock icon, Super+Shift+W,
  or the command).
- **Lock screen** (with `[lock_screen] live = true`): the callouts keep running,
  and the system readout and disk chart stay. File and folder names appear as
  8-digit codes, with the action and size but no paths, like the tower's
  screen-share obfuscation.
- **Nothing covers the panels**: callouts that end up over the readout or disk
  chart (for example after unlocking) move to a free row, their leader lines
  are drawn around the panels, and status messages stop short of them.

## Settings

New, in `[system_monitor]`:

| Setting | Default | |
|---|---|---|
| `disk` | `true` | show the disk chart |
| `disk_every` | `"30m"` | how often the home folder is re-measured |

Changed, in `[lock_screen]`:

| Setting | Default | |
|---|---|---|
| `show_names` | `false` | `false` now shows codes on the lock screen instead of hiding the callouts; `true` shows real names. `[privacy] text = "none"` still hides callouts everywhere |

## Other changes

- Plain `DISK` and `SYSTEM` headers on the lower-right panels.
- The README opens with a screen recording, and the bundle's glibc requirement
  is stated correctly (2.34+, checked by the release workflow).
- Dependency updates (`glam` 0.34.2, `log` 0.4.35).

## Upgrading from 0.1.0

Install as before (prebuilt bundle: `gits-file-visualizer/install.sh`; from
source: `tools/install-user.sh`), then run `gits-restart` or restart GNOME Shell
(X11: Alt+F2, `r`; Wayland: log out and in). Existing configs keep working: the
new settings have defaults. The first disk measurement takes 10-30 s on a large
home folder.

## Install

Prebuilt bundle (x86_64 Linux, glibc 2.34+, Ubuntu 22.04 or newer; no Rust
needed):

```sh
tar xzf gits-file-visualizer-linux-x86_64.tar.gz && gits-file-visualizer/install.sh
```

Verify the download with the `.sha256` file or its build attestation
(`gh attestation verify <file> --repo iliabaranov/gits-file-visualizer`).

## Known limitations

- The screensaver and the lit lock screen are GNOME 45+ only; GNOME 47+ is
  untested, and so is the GNOME 42-44 extension since 0.1.0.
- The disk chart covers the home folder only; the gauge shows the whole disk.
