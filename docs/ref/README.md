# Reference frames

as private look-dev reference for this project.

- `hack-tower-wide.jpg` — YouTube thumbnail of the hacking scene (`idEMI562YM0`).
- `sb_M0.jpg` … `sb_M4.jpg` — YouTube storyboard sprites of the same clip
  (5×5 grids, one frame every 2 s, in order).
- `hack-keyframes.jpg` — enlarged key panels referenced in `docs/DESIGN.md` §3.
- `ship-sequence-zeami-verse.jpg` — ship interior with the Zeami verse.
