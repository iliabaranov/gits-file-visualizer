# gits-file-visualizer

A live GNOME desktop wallpaper that renders your filesystem as a glowing gold
3D cylinder, in the style of the LOCUS SOLUS hack in *Ghost in the Shell 2:
Innocence*. Files are shown as segments, and reads, writes, creations and
deletions are visualized in real time.

Targets Ubuntu 22.04, 24.04 and 26.04 (GNOME 42 / 46 / 50, Wayland and X11).

Status: design phase. See [docs/DESIGN.md](docs/DESIGN.md).
